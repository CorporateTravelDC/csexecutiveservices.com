# csexecutiveservices-website

Source for **[www.csexecutiveservices.com](https://www.csexecutiveservices.com)** — public-facing website for CS Executive Services, LLC.

## Repository layout

```
www/                    Static site (served by nginx from /var/www/csexecutiveservices.com)
  index.html            Single-page site — generated by Claude Opus 4.8
  css/style.css         (extracted from index.html for maintainability)
  js/main.js            (extracted from index.html for maintainability)
contact-api/            FastAPI contact form backend (fixes 405 on /api/contact)
  main.py               POST /api/contact → SMTP email → JSON
  requirements.txt
  Containerfile
  csexec-contact.container   Podman Quadlet (systemctl --user)
  contact.env.example   SMTP credential template (copy to /etc/corporatetraveldc/contact.env)
nginx/
  www.csexecutiveservices.com.conf    nginx server block
docs/
  DEPLOY.md             Deployment runbook
```

## Deployment (Pi 5)

### 1. Build and install contact API

```bash
cd /opt/csexec-website/contact-api
sudo podman build -t localhost/csexec-contact:latest .

# Drop env file
sudo cp contact.env.example /etc/corporatetraveldc/contact.env
sudo chmod 0600 /etc/corporatetraveldc/contact.env
# Edit with real SMTP credentials

# Install Quadlet
cp csexec-contact.container ~/.config/containers/systemd/
systemctl --user daemon-reload
systemctl --user enable --now csexec-contact.service
systemctl --user status csexec-contact.service

# Verify
curl http://127.0.0.1:8002/healthz
```

### 2. Deploy static site

```bash
sudo mkdir -p /var/www/csexecutiveservices.com
sudo cp -r www/* /var/www/csexecutiveservices.com/
sudo chown -R nginx:nginx /var/www/csexecutiveservices.com
```

### 3. Install nginx vhost

```bash
sudo cp nginx/www.csexecutiveservices.com.conf /etc/nginx/conf.d/
sudo nginx -t && sudo systemctl reload nginx
```

### 4. Cloudflare tunnel

Add route in Cloudflare dashboard:
- `www.csexecutiveservices.com` → `http://127.0.0.1:80`
- `csexecutiveservices.com`     → `http://127.0.0.1:80`

## Contact form (405 fix)

The previous site returned **405 Method Not Allowed** on form POST because nginx had no
handler for POST requests to `/api/contact`. The fix is this three-part chain:

```
Browser fetch() POST /api/contact
  → nginx proxy_pass http://127.0.0.1:8002/api/contact
    → FastAPI contact-api (port 8002)
      → SMTP email to reservations@csexecutiveservices.com
      → JSON {"status":"received"} back to browser
```
